# Instalación

## Requisitos

- Android **8.0** o superior
- WiFi de la UPR
- Credenciales del proxy

No funciona en iOS, Windows, macOS, Linux ni Android TV.

## Pasos

### 1. Descarga el APK

https://github.com/storm2801/upr-proxy/releases/latest

### 2. Desactiva Play Protect temporalmente

Google bloquea APKs que no vienen de Play Store.

1. Play Store → tu perfil → Play Protect
2. ⚙️ (arriba a la derecha)
3. Desactiva "Analizar apps con Play Protect"

Se reactiva solo en unos días.

### 3. Permite instalar apps desconocidas

Ajustes → Aplicaciones → Acceso especial → Instalar apps desconocidas → elige tu navegador → activa.

Rutas alternativas:
- Samsung: Ajustes → Biometría y seguridad → Instalar apps desconocidas
- Xiaomi: Ajustes → Privacidad → Permisos especiales

### 4. Instala el APK

Gestor de archivos → Descargas → toca el APK → Instalar.

### 5. Configura

| Campo | Valor |
|---|---|
| Servidor | `proxy.upr.edu.cu` |
| Puerto | `8080` |
| Usuario | tu usuario UPR |
| Contraseña | tu contraseña del proxy |

Pulsa **Conectar** y acepta el permiso de VPN.

## Problemas comunes

- "App no instalada" → desinstala la versión anterior (firma distinta).
- "Play Protect bloqueó" → repite el paso 2.
- No conecta → usa Probar conexión en la app.
- La VPN no se desconecta → espera 6 s. Si sigue, reinicia el teléfono.

## Actualizar

La app avisa sola cuando hay versión nueva. Pulsa Actualizar ahora y sigue los pasos. No hace falta desinstalar.
