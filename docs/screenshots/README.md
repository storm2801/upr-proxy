## Recomendaciones

- Formato: PNG
- Ancho: 720-1080 px
- Fondo: el de la app (sin marcos ni sombras)
- Sin datos sensibles: sin credenciales reales, sin SSID, sin operador

## Cómo tomarlas

1. Instala la app en un dispositivo o emulador.
2. Ajusta el estado deseado.
3. Captura con Power + Volume Down.
4. Recorta con cualquier editor.
